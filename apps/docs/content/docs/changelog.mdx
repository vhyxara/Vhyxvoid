## October 2026

**Dashboard**

- **API client**: send requests from the browser through the platform (no CORS), with collections and folders the team shares, environments with encrypted secrets, bearer, basic, API key and HMAC auth, JSON, GraphQL, form, multipart and file bodies, checks without code (status, headers, JSON path, JSON schema, time, size), captures that chain requests, timings, code in five languages, history, collection runs with reports, imports from curl, Postman, OpenAPI and HAR, and [`vhyxvoid test`](/cli/test) to run a collection in CI. See [API client](/dashboard/api-client).
- **Mock APIs, part 2**: resources (a REST collection with stored data from a seed, filters, sorting, paging, reset), recording endpoints from real traffic in the inspector, import from Postman, Mockoon and HAR, export to Mock Service Worker, Postman and Mockoon, and [`vhyxvoid mock`](/cli/mock) to run a mock offline.
- **Mock APIs**: a working API at a public URL with no backend running. Start from a template or an OpenAPI file; endpoints with path parameters, several responses chosen by rules, in turn or at random, templating with realistic fake data, latency, CORS, try-it, OpenAPI export. Mock first next to a live agent, or only while it is offline. See [Mock APIs](/dashboard/mock-apis).
- **Agents** on the Tunnels page: health, version, uptime, last ping, requests in flight and the key of every connected agent, an update note for old agents, recent disconnects, and **Stop** for owners and admins. See [Tunnels](/dashboard/tunnels#agents).
- **Traffic rules**: per-tunnel mocks, injected errors and latency, redirects, path rewrites and header changes, applied before requests reach your machine, plus maintenance answers while the agent is offline. See [Traffic rules](/dashboard/traffic-rules).
- **Traffic charts** on the Tunnels page and the overview: requests per minute, 15 minutes or 2 hours, split into successful, `4xx` and `5xx`, with error rate and average answer time per tunnel. See [Tunnels](/dashboard/tunnels#traffic).
- **Activity**: every change in a workspace (members, keys, access rules, domains, alerts, inbox) and every tunnel connect and disconnect, with CSV export for owners and admins. See [Activity](/dashboard/activity).
- **Usage and trial notices**: owners and admins hear about 80% and 100% of the monthly requests and about a trial ending, once each. See [Alerts](/dashboard/alerts#usage-and-trial-notices).
- **Request capture switch**: a workspace can stop the request inspector from storing anything. See [Request inspector](/dashboard/request-inspector#turning-capture-off).
- Earlier this month: [request inspector and replay](/dashboard/request-inspector), [tunnel access rules](/dashboard/tunnel-access), the [webhook inbox](/dashboard/webhook-inbox), [custom domains](/dashboard/custom-domains) and [alerts](/dashboard/alerts).

**CLI and CI**

- `vhyxvoid doctor` checks your key, local server, hub, sign-in and custom domain DNS, and tells you how to fix what is wrong. See [doctor](/cli/doctor).
- A [GitHub Action](/integrations/github-actions) gives a CI job a public URL and comments it on the pull request.

**Security**

- After 10 wrong tunnel passwords in a minute from one address, the hub answers `429` for the rest of that minute.
- Sign-ins expire after 90 days (dashboard) and 30 days (admin console) however often they refresh. Admin accounts lock for 15 minutes after 5 wrong passwords.
