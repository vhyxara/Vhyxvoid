VhyxVoid connects a server running on your machine to a public HTTPS URL. A small agent runs next to your server, holds a connection to the VhyxVoid hub, and forwards incoming requests to `localhost`. The URL stays the same between runs, so you can put it in webhook settings, `.env` files, and teammates' chats.
