Open **Activity** under a workspace. Everyone in the workspace can see it; the newest entries are at the top, grouped by day, and it refreshes every minute.

## What is recorded

| Area | Entries |
| --- | --- |
| Members and workspace | invitations sent, cancelled and accepted; members removed or leaving; role changes; ownership transfers; workspace created or renamed |
| API keys | created, revoked (including keys revoked because their owner left), rotated |
| Tunnels | connected and disconnected (with how long the connection lasted), disconnected by the hub, [access rules](/dashboard/tunnel-access) and share links, [custom domains](/dashboard/custom-domains), the [webhook inbox](/dashboard/webhook-inbox), replays and clearing in the [request inspector](/dashboard/request-inspector), switching request capture on or off, saving or removing [traffic rules](/dashboard/traffic-rules), creating, changing, importing into and deleting [mock APIs](/dashboard/mock-apis), and agents stopped from the dashboard |
| Alerts | [alerts](/dashboard/alerts) created, changed, paused, resumed and deleted |
| API client and performance | [collections](/dashboard/api-client) created, imported, changed and deleted, collection runs, environments created, changed and deleted (sending a single request is not recorded), [load tests](/dashboard/performance#load-tests) started and stopped, [monitors](/dashboard/performance#monitors) created, changed, paused and deleted, and [API docs](/dashboard/api-docs) created, published, restored, shared, put on a domain and deleted (saving a draft is not recorded) |
| Team space | [channels](/dashboard/team-space#chat) created, changed, archived and deleted, [documents](/dashboard/team-space#docs) created, restored and deleted, and [issues](/dashboard/team-space#issues) created and deleted (messages, edits and comments are not recorded here; issues keep their own activity) |

Each entry names the person who made the change. Owners and admins also see the IP address it came from. Passwords, secrets and tokens are never recorded, only that they were set or removed.

Use **Show** to see one area only, and switch off **Tunnel connects and disconnects** when a busy workspace's connection entries hide the changes you are looking for. **Show older activity** at the bottom loads the next 50.

## Export

Owners and admins can choose **Export 30 days (CSV)**. The file has one row per entry: time (UTC), action, the person's name and email, the member an action was about, the resource, details as JSON, IP address and browser. Cells that a spreadsheet would treat as a formula are prefixed with `'`.
