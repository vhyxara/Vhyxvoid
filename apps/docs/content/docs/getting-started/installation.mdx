VhyxVoid ships four npm packages. Pick by what you're doing:

| You want to… | Install | Guide |
| --- | --- | --- |
| Tunnel any local server, from the command line | `@vhyxvoid/agent` | [Quickstart](/getting-started/quickstart) |
| Start the tunnel from inside a Next.js app | `@vhyxvoid/next` | [Next.js](/integrations/nextjs) |
| Start the tunnel from inside an Express or Fastify app | `@vhyxvoid/middleware` | [Express](/integrations/express), [Fastify](/integrations/fastify) |
| Call a tunneled server from code | `@vhyxvoid/sdk` | [SDK overview](/sdk/overview) |

For most projects, install the one you need as a development dependency:

```bash
npm install --save-dev @vhyxvoid/agent
```

You can also run the agent without installing it, with `npx @vhyxvoid/agent`, as the quickstart does.

<Callout title="Native module">
  The agent depends on `better-sqlite3`, which includes a native component. On common platforms npm downloads a prebuilt binary; on others it compiles one, which needs a C++ toolchain. The Next.js, Express, and Fastify integrations run the agent in-process without its on-disk queue, but they still install the same dependency.
</Callout>

<Callout type="warn" title="The Next.js integration">
  Use `@vhyxvoid/next` for Next.js. `@vhyxvoid/middleware` is documented here for Express and Fastify only.
</Callout>
