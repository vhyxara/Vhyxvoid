## 5. How to run the stack locally (as used this session)

Postgres 16 and Redis from apt, no `.env` files (local `.env` files point at
production — see `shared/LOCAL_DEV_BACKEND.md`). Env used: `DATABASE_URL`
to a local database, `UPSTASH_REDIS_REST_URL=http://127.0.0.1:8079` with
`scripts/upstash-rest-standin.mjs`, generated RSA keys as `PRIVATE_KEY_B64` /
`PUBLIC_KEY_B64`, `SERVER_HMAC_PEPPER`, `HUB_DOMAIN=vv.test`,
`HUB_INTERNAL_URL=http://127.0.0.1:9101` + `HUB_INTERNAL_SECRET`,
`SUPER_ADMIN_EMAIL/PASSWORD`, `PORT=9100`, `HUB_PORT=9101`. Then
`apps/api: pnpm seed && pnpm dev`, `apps/hub: pnpm dev`, `apps/web:
NEXT_PUBLIC_API_URL_LIVE=http://localhost:9100/api/v1 next dev -p 4000`.
Tunnel requests: `curl -H "Host: <slug>--<label>.vv.test" localhost:9101/...`.
